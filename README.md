# Tinker Notes

A study notebook for an Arduino / Tinkercad robotics course. The learner writes class notes in his own words. The app keeps them organized and turns them into hands-on practice.

> **Live demo:** <https://tyrunt-a.github.io/study-companion/>

## What it does

- **Organizes your notes** into a map of concepts and shows how far along you are with each one.
- **Daily Tinkercad challenges** built only from what you've written down. Each one picks up where the last one left off.
- **Helps when something fails:** it tells you whether you misapplied something you already know or ran into something you haven't learned yet. You decide whether to learn it now.
- **Error notebook** to see how far you've come.
- **No grades, no accounts.** Your notes stay on your own computer.

## Built with a real user

This project is being developed with one real learner, a friend taking a free vocational robotics course. Each version is shaped by his feedback.

## Try it

Open the live demo in Chrome or Edge. Then go to **Ajustes** (Settings) and add a free Google Gemini API key from <https://aistudio.google.com/apikey>.

## Privacy

To improve the service, the app sends anonymous technical usage data (which feature was used, response time, token counts, and errors). Notes, code and API keys are never sent.
